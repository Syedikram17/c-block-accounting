DEPLOY TO GITHUB PAGES
1. Extract this ZIP file.
2. Open the c-block-accounting GitHub repository.
3. Upload index.html directly into the repository root (same level as README.md).
4. Commit the changes to the main branch.
5. In Settings > Pages, select Deploy from a branch, branch main, folder /(root), then Save.
6. Wait for GitHub Pages to publish, then refresh your website.
