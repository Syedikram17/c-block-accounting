C-BLOCK FINANCE DESK
====================

DEPLOY TO GITHUB PAGES
1. Extract this ZIP file.
2. Open your GitHub repository: https://github.com/Syedikram17/c-block-accounting
3. Upload index.html directly into the repository root (not inside another folder).
4. If GitHub asks, replace the existing index.html.
5. Commit the changes.
6. In Settings > Pages, select Deploy from a branch, branch main, folder /(root), then Save.
7. Wait for deployment and open https://syedikram17.github.io/c-block-accounting/

DEMO LOGIN
Username: admin
Password: Cblock@123

FEATURES
- Login and logout
- Dashboard with total sales, expenses and net profit
- Add/manage clients
- Add/manage sales linked to clients
- Add/manage expenses and categories
- Recent transactions and reports
- CSV export and JSON backup/restore
- Responsive layout

IMPORTANT
This is a static browser-based prototype. Login credentials are visible in the HTML source and are not secure authentication.
Records are stored in localStorage in the current browser/device only. They do not sync between devices or users.
Do not use this as statutory accounting or tax-compliance software. Connect a secure backend and have accounting/tax workflows reviewed before production use.
